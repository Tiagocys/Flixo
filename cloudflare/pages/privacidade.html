Política de Privacidade

Última atualização: 3 de setembro de 2026.

1. Dados que coletamos

Coletamos dados necessários para operar o Copacabena, como nome, e-mail, identificador da conta, autenticação via Google/Supabase, projetos criados, arquivos enviados, vídeos renderizados, legendas, capas, logs técnicos e informações de assinatura.

2. Login com Google

Ao entrar com Google, usamos sua conta para autenticação e separação dos seus projetos. Se você conectar o YouTube, podemos acessar apenas os escopos autorizados para visualizar sua conta do YouTube e enviar vídeos quando você solicitar.

3. Conteúdos e arquivos

Os arquivos que você envia ou gera podem ser processados localmente pelo backend e armazenados em serviços como Cloudflare R2 e Supabase para permitir download, edição, histórico e recuperação do projeto ativo.

4. Pagamentos

Pagamentos e assinaturas são processados pela Stripe. O Copacabena não armazena dados completos de cartão. Armazenamos identificadores de cliente, assinatura, status do plano e informações necessárias para liberar ou limitar recursos da ferramenta.

5. Uso dos dados

Usamos os dados para autenticar sua conta, processar vídeos, gerar cortes, entregar arquivos, permitir envio ao YouTube, gerenciar assinatura, prevenir abuso, diagnosticar erros e melhorar a estabilidade do serviço.

6. Compartilhamento com provedores

Compartilhamos dados somente quando necessário para operar a ferramenta, incluindo provedores de autenticação, armazenamento, pagamento, infraestrutura, APIs de IA e plataformas conectadas por você, como Google e YouTube.

7. Segurança

Aplicamos controles técnicos razoáveis para proteger os dados, incluindo autenticação, segregação por usuário e uso de chaves de API no servidor. Nenhum sistema é totalmente imune a falhas, especialmente durante fase beta.

8. Retenção e exclusão

Podemos manter dados enquanto forem necessários para entregar o serviço, cumprir obrigações técnicas, resolver disputas, prevenir abuso ou manter o projeto ativo. Recursos de exclusão e limpeza podem ser ajustados conforme a evolução da plataforma.

9. Seus controles

Você pode desconectar integrações, cancelar assinaturas quando disponível, excluir projetos pela interface e solicitar informações ou remoção de dados pelos canais de contato do Copacabena.

10. Alterações nesta política

Podemos atualizar esta política conforme o produto evolui. A versão publicada nesta página indica a data da última atualização.
